# Dashboards — build instructions

Both dashboards read the CSV feeds in this folder (regenerated by
`make report`, so they always match the pipeline). Publishing is manual;
each build is ~30–45 minutes.

**Design rules (both tools)**
- One question per page; the page title states the finding, not the topic.
- One colour for the thing that matters (#2a78d6), grey for the rest.
- Every axis labelled with units; every chart says what period it covers.
- Footer on every page: "Public data (Kaggle/Criteo/MineThatData), personal
  project, refreshed <date>."

## Tableau Public

1. Sign in at public.tableau.com → Create → Web authoring (or Tableau Public
   desktop app). Connect → Text file → `campaign_kpis.csv`; add
   `segment_cuts.csv` and `weekly_monitor.csv` as additional data sources.
2. **Page 1 — "Campaign 1178 pays the most per conversion".**
   Bars: campaign_id vs cpa. Add spend as bar labels. Filter card: age,
   gender via `segment_cuts.csv` sheet swap (or build the explorer on
   `ad_kpis.csv` with campaign/age/gender filters).
3. **Page 2 — "Orders plateau in 2018; Black Friday is the only spike above
   the band".** Line: purchase_week vs orders from `weekly_monitor.csv`.
   Add reference band: Analytics → Distribution Band, fixed from the stable
   stretch values in `monitor_flags.csv` (the band column), or compute
   AVG ± 3*STDEV over Jan–Jul 2018 with a table calculation.
   Colour weeks outside the band red (calculated field).
4. Dashboard → phone layout check → Publish ("Save to Tableau Public").
   Copy the public URL into the repository README.

## Looker Studio

1. Upload `weekly_monitor.csv` and `campaign_kpis.csv` to a Google Sheet
   (one tab each) — Looker Studio's native CSV connector also works.
2. lookerstudio.google.com → Create → Data source → the sheet.
3. **Page 1**: time-series chart, dimension purchase_week, metric orders;
   add late_share as a second chart (never a second axis on the first).
   Scorecards: total orders, late share, average review score.
4. **Page 2**: table of campaign KPIs with conditional colour on cpa.
5. Share → "Anyone with the link can view". Copy the URL into the README.

## Why no Power BI

Desktop Power BI needs Windows; this project was built on a Mac. The claim
stays "Tableau Public + Looker Studio", and the design carries over.
